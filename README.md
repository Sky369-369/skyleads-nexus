## 🚀 **Quick Start Guide**

### **1. Installation**

```bash
# Clone or navigate to the project
cd d:\skylead

# Install dependencies
npm install

# Copy environment file
copy .env.example .env

# Edit .env with your API keys
notepad .env
```

### **2. Configuration**

Edit `.env` file and add your credentials:

```env
# Required: Payment Processing
STRIPE_SECRET_KEY=sk_live_your_stripe_key
ETH_WALLET_ADDRESS=your_ethereum_wallet
SOL_WALLET_ADDRESS=your_solana_wallet

# Required: Database
MONGODB_URI=mongodb://localhost:27017/skylead

# Optional: Email notifications
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

### **3. Start the Server**

```bash
# Development mode
npm run dev

# Production mode
npm start
```

Server will be running at: **http://localhost:3000**

## 🔧 **Advanced Configuration**

### **Setting Up Crypto Payments**

#### **Ethereum (ETH/USDT)**
```javascript
// Install Web3
npm install web3 ethers

// Configure in .env
ETH_WALLET_ADDRESS=0x...
ETH_PRIVATE_KEY=your_private_key
INFURA_PROJECT_ID=your_infura_id
```

#### **Solana (SOL)**
```javascript
// Install Solana Web3
npm install @solana/web3.js

// Configure in .env
SOL_WALLET_ADDRESS=your_sol_address
SOL_PRIVATE_KEY=[your,private,key,array]
```

#### **Bitcoin (BTC)**
```javascript
// Install Bitcoin libraries
npm install bitcoinjs-lib

// Configure in .env
BTC_WALLET_ADDRESS=your_btc_address
BTC_PRIVATE_KEY=your_private_key
```

### **Setting Up Bank Transfers**

#### **Stripe Integration**

